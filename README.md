# Эмоции Арены

Фанатская игра для вечеринки по эмоциям Clash Royale: ритм-челлендж под бит и викторина на очки.
У каждой эмоции — её оригинальный звук из игры.

Сайт: https://akexbuk00.github.io/emotsii-areny/

Неофициальный фанатский проект, не связан с Supercell и не одобрен ею.
Картинки — из Supercell Fan Kit, звуки — из файлов игры (github.com/Henrylq/Clash-Royale-SFX)
и вики Clash Royale. Использование — по Supercell Fan Content Policy:
https://supercell.com/en/fan-content-policy/ — только бесплатно и некоммерчески.
